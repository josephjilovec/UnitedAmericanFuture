# National capacity concept imagery

Ten original images were generated with the built-in image-generation tool for NC–02 through NC–06: one hero and one editorial-detail image per initiative. All images depict fictional settings and people. They do not document UAF facilities, staff, partners, fieldwork, operational approvals, clinical shipments, accessibility compliance, or project results.

The [image manifest](images.json) records the exact prompts, original dimensions and SHA-256 hashes, generation method, and all optimized output paths. The source PNG originals are retained in the generation session; only responsive WebP derivatives are used on the public site. Image descriptions and visible concept captions accompany them.

Each image has 640, 960, and 1600-pixel WebP variants (without upscaling). The hero uses responsive `srcset` and high fetch priority; secondary and directory images load lazily. No generated image is used as a precise map, chart, engineering drawing, or proof of a real operation.
