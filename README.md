# United American Future (UAF)

Responsive static nonprofit concept website.

## Run
Open `index.html` directly or serve this folder with any static server.

## Launch checklist
- Replace concept copy with verified organizational facts.
- Add verified nonprofit/tax status only after legally established.
- Connect the contact form to a production endpoint.
- Add privacy/terms policies appropriate to actual data collection.
- Add real program, governance, financial, and impact information when available.

Built as a lightweight HTML/CSS/JS site with no build dependencies.
